Here is how to solve the problem:
The user needs some specific contracts (قرارداد)
The contracts are connected to Cost Breakdown Structure or CBS (ساختار شکست هزینه)
A CBS row should always belong to a valid WBS item (برنامه‌ریزی دارند)
The contracts are related to a project called «فاز اول - ناصری»
So vw_CBS, vw_Projects, vw_Contracts and vw_WBS needs to be joined.

  "generated_query": "SELECT PC.ProjectName, PC.ProjectNO, PC.ContractNO

                  vw_Projects AS PR ON PC.ProjectKEY = PR.ProjectKEY INNER JOIN
