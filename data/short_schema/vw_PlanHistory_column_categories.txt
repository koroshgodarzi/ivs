vw_PlanHistory — column categories (concise)

1) Record & Hierarchy IDs
- Unique row identifier plus links to the project plan and WBS (work breakdown) nodes.

2) Naming / Labels
- Human-readable names for the project, WBS element, and project plan.

3) Snapshot Creation Time
- When this plan-history snapshot was created (Gregorian + Jalali + Y/M/D parts).

4) Planned Schedule Window
- Planned start and planned end dates for the plan (Gregorian + Jalali + Y/M/D parts).
